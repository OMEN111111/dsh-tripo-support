# UI redesign evidence

| File | What it proves |
|---|---|
| `settings-3d.png` | A dedicated `设置 → 3D 生成` section in the left navigation, with official (Tripo / Meshy / Hyper3D / HY3D) and third-party (qwenai preset) tabs and compact provider rows. |
| `settings-official-edit.png` | Official provider configuration exposes only the API key by default; advanced address/model options are collapsed. |
| `settings-official-advanced.png` | Advanced settings retain manual Base URL / model override for official providers. |
| `settings-third-add.png` | Third-party provider form lets the user define name, protocol, Base URL, model IDs and key. |
| `pill-open.png` | Composer 3D pill opens a DSH-style menu listing provider names (Tripo, qwenai, Meshy, Hyper3D, HY3D) and the active provider's models. |
| `pill-provider-expanded.png` | Clicking a provider switches the active provider and expands its model list. |
| `pill-selected.png` | Selecting a model updates the persisted selection; the pill shows the new provider/model. |
| `pill-result.json` | The selection endpoint persisted `qwenai-dashscope / Tripo/Tripo-Texture` during the test. |
| `update-panel.png` | Settings → Plugins → 3D 支持 checks the GitHub release and shows current/latest versions. |
